# This folder is not a download

`version.txt` here is a machine-readable version marker. CQRLog Enhanced
fetches it at startup to tell you when a newer version is available.
That is all it is for — there are no program files in this folder.

**To install CQRLog Enhanced, see the
[installation instructions](../README.md#install) on the front page.**

One command does the whole job:

```
bash <(curl -fsSL https://raw.githubusercontent.com/n8mus/cqrlog/master/install-cqrlog.sh)
```
